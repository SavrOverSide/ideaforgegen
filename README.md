# Lore Forge

Telegram-бот, который генерирует идеи игр, персонажей и фракции для геймдева и НРИ (RU/EN). Каждый вечер публикует идею в [@ideaforges](https://t.me/ideaforges).

- Бесплатно: 5 генераций в день
- 50 генераций за 25 ⭐, безлимит на 30 дней за 149 ⭐ (`/buy`)
- Владельцу: `/stats` (нужен `OWNER_ID` в `.env`)

Таблицы генерации лежат в [ideas/tables.py](ideas/tables.py). Установка описана в [geekdigest](https://github.com/SavrOverSide/geekdigest#установка-на-сервер-все-три-проекта-сразу).
